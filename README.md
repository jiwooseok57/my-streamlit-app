# 🏋️‍♂️ 나만의 운동 기록 대시보드

10강 실습 과제 - Streamlit을 활용한 웹 대시보드 만들기

## 📋 프로젝트 소개
- **주제**: 나만의 운동 기록 및 통계 대시보드
- **설명**: 사용자가 날짜별 운동 종류와 운동 시간(분)을 확인하고, 필터링 및 요약 지표를 통해 운동 습관을 관리할 수 있는 Streamlit 웹 애플리케이션입니다.

## ✨ 주요 기능 (필수 조건 충족)
1. **텍스트**: `st.title()`, `st.markdown()`, `st.header()` 등을 활용한 앱 제목 및 설명
2. **데이터**: `st.metric()`(요약 지표) 및 `st.dataframe()`(세부 기록 테이블) 활용
3. **차트**: `st.bar_chart()`를 활용한 일별 운동 시간 시각화
4. **위젯 및 연동**: `st.selectbox`(운동 종류 선택), `st.slider`(최소 운동 시간 선택) 위젯을 배치하여 화면 내용이 실시간으로 연동되도록 구현
